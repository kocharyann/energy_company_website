# Корпоративный сайт ООО «Энергетическая компания»

Курсовой проект, КубГУ, ФКТиПМ, 2026.
Корпоративный сайт с адаптивной вёрсткой, формой обратной связи и серверной отправкой через PHPMailer.

## Стек технологий

- HTML5, CSS3, JavaScript (vanilla)
- PHP 8.3
- PHPMailer 6.x для отправки писем по SMTP
- Apache 2.4 (.htaccess для безопасности, gzip, кэширования)
- WebP для оптимизации графики
- JSON Lines для журналирования заявок

## Структура проекта

- `index.html` — главная страница
- `send.php` — серверный обработчик формы
- `config.example.php` — шаблон конфигурации SMTP
- `.htaccess` — настройки Apache
- `css/style.css` — стили
- `images/` — графика в формате WebP
- `docs/` — PDF-документы компании
- `lib/PHPMailer/` — библиотека отправки писем
- `data/` — серверные журналы (создаются автоматически)

## Установка

1. Скопировать `config.example.php` → `config.php`
2. Указать в `config.php` реальные SMTP-данные
3. Разместить на хостинге с поддержкой PHP 8 и .htaccess
